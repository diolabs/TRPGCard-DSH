# TRPGCard 主持人插件

在 DeepSeek Harness 的聊天中查询队伍、调整角色状态和资源、处理休息，以及发放物品、金币和经验。右侧打开现有 TRPGCard 主持人页面，页面和工具使用同一个房间。

适用版本为 DeepSeek Harness 桌面端 `0.2.2-rc.5`。

## 安装与连接

1. 在桌面端打开「插件 → 添加插件」，输入 `https://github.com/diolabs/TRPGCard-DSH`，安装后点击「立即启用」。如果之前装过同名旧版，先从插件页卸载旧版。
2. 在聊天的右侧栏打开「TRPGCard 主持人」。插件会打开 `www.trpgcard.com`。登录后选择有主持权限的房间，等待显示「已连接房间」。
3. 在聊天中提问，例如「看看全队现在的血量，谁低于一半？」。修改数据时说清楚对象、动作和数量。经验调整先预览，再确认入账。

安装使用公开仓库。房间访问和主持权限由 TRPGCard 的登录账号决定。

## 工具范围

- 查询房间、队伍、角色状态和资源、场景、时间与活动。
- 调整状态、血量和 D&D 资源，处理短休和长休。
- 从规则包目录发放物品，调整金币；D&D 经验使用预览和确认流程。

执行修改前会现场确认原页面仍连接对应房间。切房、退出登录或连接失效后，需要恢复连接。已发出的请求如未取得明确结果，不会自动重放；应先查询实际状态。

## 断开与卸载

在右侧点击「断开连接」，或从 DSH 插件管理中卸载插件。插件不包含 TRPGCard 网站服务，卸载插件不会删除原站角色或房间。
